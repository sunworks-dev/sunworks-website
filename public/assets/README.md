- `horang.webp`: existing sunworks-owned artwork, converted from `apps/hanja-study-app/flutter_app/assets/characters/welcome.png` without visual editing.
- `hanja-icon.webp`: existing sunworks-owned app icon, resized from `apps/hanja-study-app/flutter_app/assets/icon/app_icon.png`.
- The owner explicitly supplied the app directory and web deployment for this product introduction.
- Both images retain source attribution in adjacent JSON metadata. These are existing assets, not images generated during this website task.

- `solar-engine.webp`: original mathematical Three.js sculpture rendered from `src/scripts/solar-engine.ts`, exported from the original transparent WebGL framebuffer in Phi Agent Space and converted to WebP without visual editing. It preserves the visual identity when JavaScript or WebGL is unavailable. Details are in the adjacent provenance JSON.
- `../social-card.png`: original 1200×630 browser-rendered typography, geometric logo, and the same sculpture; embedded PNG attribution and adjacent provenance JSON. Temporary render routes are removed before publishing.
