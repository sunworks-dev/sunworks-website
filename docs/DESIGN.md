# Design System: sunworks

## Overview

**Creative North Star: "쓸모 있는 딴생각을 찍는 작은 인쇄소"**

“쓸모 있는 딴생각.”은 썬웍스가 일상의 발견을 직접 쓰고 싶은 앱과 웹서비스로 만드는 태도다. 따뜻한 종이, 짙은 잉크, 노랑과 주황의 해, 큼직한 한글 활자로 호기심과 만드는 즐거움을 전한다. 인쇄소는 시각적 은유이며 실제 사업 소개는 자체 디지털 제품 회사다.

사람의 관찰과 판단이 문장의 주어다. AI는 탐색과 구현을 돕는 작업 도구로 설명한다. 교육은 첫 제품 어흥!한자의 영역이며 회사 전체를 제한하지 않는다. 빈티지 느낌은 인쇄풍 그림·색·활자의 조합으로 내고, 본문과 조작은 명료하게 유지한다.

**Key Characteristics:**

- 소유자가 제공한 한글 로고와 노랑·주황 그라데이션.
- 한글 포스터 활자, 따뜻한 종이 바탕, 여유 있는 본문.
- 짧고 구체적인 한국어와 실제 제품·출시 상태.
- 눌렀을 때 반응하고 멈추는 인쇄 동작, 저장할 수 있는 질문 카드.

이 문서는 2026-10-07 구현을 기준으로 기존 코발트·3D 체계를 교체한 브랜드 가이드다. 토큰은 앞의 YAML이 기준이며, 페이지 구성은 [홈 화면 계약](surfaces/home.md), 사업 사실은 [PRODUCT.md](PRODUCT.md)를 따른다. 구현 근거: [전역 스타일](../src/styles/global.css), [홈 컴포넌트](../src/components/Home.astro), [문구 사전](../src/i18n.ts), [공통 레이아웃](../src/layouts/Base.astro). 로컬 QA 캡처는 `.impeccable/review/`에 별도 보관하며 공개 문서 자산은 아니다.

한국어 홈(`/`)이 기준이고 영어 홈(`/en/`)은 같은 구성·색·그림을 쓴다. 두 언어의 문구는 [문구 사전](../src/i18n.ts) 한 곳에 있다. 영어 문구는 한국어를 옮긴 번역문이 아니라 같은 태도로 따로 쓴 문장이다.

### 홈 브랜드 필름 (2026-10-08)

소유자 요청으로 첫 화면의 큰 제목과 그림을 전체 폭 **16초 무음 루프**로 통합했다. 한국어·영어 각각 가로 1920×960(2:1), 세로 1080×1440(3:4), 30fps를 사용한다. 기존 종이·잉크·노랑·주황·주홍과 자체 제공 글꼴을 유지한다. 종이의 휘어짐·뒤집힘·풀림, 큰 활자의 정합과 해 모양 마스킹, 종이 오려내기가 이어진다. 입체감은 이 필름 안의 종이 접힘을 표현하는 데만 사용하며 일반 UI의 3D 조형물 체계로 확장하지 않는다.

소유자의 후속 피드백에 따라 방사형 햇살·해의 살·욱일기처럼 읽힐 수 있는 확산 무늬를 영상에서 전부 제거했다. 마지막 로고 정지도 없앴다. 단색 원형 해와 처음의 제목·종이 구도로 돌아오며 이어 재생된다. 정지 포스터에 큰 제목을 포함하며 모션 감소·데이터 절약 설정에서는 명시적인 재생 전까지 영상을 요청하지 않는다. JavaScript 없는 환경에서도 소개와 제품 링크를 읽을 수 있다. 재생·일시 정지 버튼의 누르기 영역은 44px 이상이다. 화면 밖과 숨겨진 탭에서는 일시 정지하며 한·영 컨트롤 문구는 `src/i18n.ts`에서 관리한다.

현재 홈 첫 화면의 구현 기준은 [MotionHero](../src/components/MotionHero.astro), [홈 화면 계약](surfaces/home.md), [제작 기록](motion-production.md)이다. 아래 첫 포스터의 2열 배치·정적 그림·활자 크기 설명은 영상 교체 전 디자인 기록이다. 다른 섹션의 토큰·배치 규칙은 유지한다.

#### 2026-10-08 다시 쓰기

소유자가 “AI스럽고 어색해서 읽히지 않는다”고 지적해 화면 문구를 다시 썼다. 한국어·영어 카피 비평 패널(카피라이터·학부모·교열자 세 관점)로 세 차례 고쳐, 모든 섹션을 7점 이상, 평균 약 8점으로 맞췄다. 지금 문체 규칙은 다음과 같다.

- 본문은 말하듯 해요체로 쓴다. 제목은 명사형이나 평서형을 섞어 리듬을 바꾼다. “만드는 방식”의 제목 네 개는 작업 규칙처럼 평서형(-다)으로 맞춘다.
- 추상명사(발견·시작·배움) 대신 누구나 겪은 장면(샤워, 깜지, 노트북, 사흘 만에 덮는 단어장)을 쓴다.
- 관용구는 섹션마다 한두 개까지만 쓴다. “딴생각”은 섹션마다 한 번 정도만 쓴다.
- 제품 사실은 공식 소개 사이트에 공개된 것만 쓴다(아래 “제품·이미지·오류 페이지”). 어흥!한자는 서버 없이 기기에 기록하는 앱이므로 서버를 언급하지 않는다.
- 영어는 “web services” 대신 “websites”를 쓴다. 급수는 미국 독자가 학년으로 읽으므로 “test levels”로 쓴다. 웹 베타 링크에는 “(in Korean)”을 붙인다. Hanja는 설명 첫 문장에서 한 번 풀어 쓴다.

#### 이름과 카피 연결 (2026-10-08)

소유자가 회사 이름과 카피를 더 강하게 묶어 달라고 요청했다. 독립 전략가 1명과 한국어·영어 비평 패널로 검토해 아래 원칙을 정했다.

- 한국어 독자는 ‘썬’을 해(sun)로 읽지만 ‘웍스’를 ‘돌아가다’로 읽지 않는다. 그래서 한국어는 해·빛·떠오르다로 묶고, Works는 영문 문구와 장식 포스터가 맡는다.
- 해 표현은 화면에 해 그림이 있는 곳에만 둔다. 대상은 히어로 그림 설명, 해 그라데이션 띠, 해 도장이 찍힌 인쇄 카드다. 영문 포스터는 SUN과 WORK를 주홍으로 드러낸다.
- 회사 이름의 유래 이야기는 쓰지 않는다(소유자 결정).
- 760px 이하에서 띠의 둘째 줄은 숨긴다. 단 한국어 페이지는 한국어 방문자 대부분이 모바일이라 “딴생각도 빛을 봐야지.”를 영문 줄 아래에 남긴다. 영문 줄이 남는 폭을 먼저 써서 화살표는 첫 줄 오른쪽에 머문다.
- 피할 표현: “쥐구멍에도 볕 들 날” 같은 속담 비틀기(딴생각을 초라하게 만든다), “제대로 돌아가는 앱”·“apps that work”(다른 제품을 깎아내리는 대비로 읽힌다), “A LOT OF WORK”(고생으로 읽힌다).

## Colors

종이와 잉크가 읽기를 맡고, 해의 따뜻한 색이 큰 장면과 작은 반응을 만든다. 앞의 색상 토큰은 [전역 CSS의 실제 변수](../src/styles/global.css)와 같다.

### Primary

- **해의 노랑 (`yellow`):** 버튼 hover, 어두운 면의 강조, 선택 텍스트와 인쇄 카드의 중심.
- **인쇄 주황 (`orange`):** 인쇄 카드의 해를 구성하는 중간 색. 로고에서 가져온 따뜻한 계열을 잇는다.

### Secondary

- **주홍 잉크 (`red`):** 큰 강조 문구, 큰 굵은 disclosure 제목의 hover, 해의 바깥 원. 작은 본문의 강조색으로 쓰지 않는다.

### Neutral

- **따뜻한 종이 (`paper`):** 기본 바탕, 인쇄 카드, 짙은 면의 주 텍스트.
- **짙은 잉크 (`ink`):** 본문, 주요 버튼, 인쇄소 바탕.
- **로고의 검정 (`black`):** 로고 배경과 이어지는 헤더·푸터.
- **보조 잉크 (`muted`):** 종이 위의 작은 보조 설명.
- **가는 구분선 (`rule`):** 내용의 경계를 알리는 선. 본문 글자색이 아니다.

### 해질녘 그라데이션과 대비

재사용 그라데이션 `--sunset`은 `linear-gradient(105deg, #ed5427 0%, #f99535 53%, #ffdc56 100%)`다. 띠·제품 섹션·마무리 면에 같은 값을 쓴다. 로고 내부 그라데이션은 원본 이미지에 포함된 별도 자산이며 이 CSS로 다시 그리지 않는다.

| 실제 조합                   | 대비            | 사용 범위                                       |
| --------------------------- | --------------- | ----------------------------------------------- |
| 잉크 / 종이                 | 13.76:1         | 본문·제목·버튼. 반전 조합도 동일                |
| 보조 잉크 / 종이            | 5.45:1          | 작은 보조 설명                                  |
| 잉크 / 해질녘 그라데이션    | 최저 4.501519:1 | 현재 불투명한 색 조합의 본문·제목               |
| 주홍 / 종이                 | 3.77:1          | 큰 디스플레이 및 큰 굵은 요약행. 일반 본문 금지 |
| 인쇄소의 옅은 보조문 / 잉크 | 9.42:1          | 인쇄소 초대 문구의 로컬 색상 (`#d2c5af`)        |

마지막 색은 인쇄소 한 곳의 값이다. 공통 색 토큰으로 확장하지 않는다. 사이드카의 8단계 색상 견본은 색을 살피기 위한 파생 램프이며 배포된 팔레트나 검증된 대비 조합이 아니다.

**The Readable Ink Rule.** 그라데이션 위의 글자는 잉크로 유지한다. 가장 짙은 구간의 대비 여유가 작으므로 색·불투명도 변경 시 전체 구간을 다시 확인한다.

## Typography

**Display Font:** Gasoek One. 한글 포스터 제목·제품 이름·질문 카드에 쓰며 실제 제공 굵기 (400)를 따른다. 대체 글꼴은 Noto Sans KR Variable, sans-serif다.

획이 매우 두꺼운 글꼴이라 자간을 좁히면 “딴생각”, “않았습니다”처럼 받침이 많은 음절끼리 붙어 덩어리로 보인다. 그래서 자간은 (+0.03em)으로 연다. 2026-10-07에 Do Hyeon으로 잠시 바꿨으나, 소유자 결정으로 Gasoek One을 유지하고 자간만 넓혔다. 같은 문장을 그려 잰 잉크 비율 측정값은 Gasoek One (0.78), Do Hyeon (0.48)이다.

**English Display:** Archivo Variable, 굵기 (750), 폭 (85%). 영어 홈(`/en/`)의 포스터 제목과 질문 카드에 쓴다. Gasoek One은 라틴 글자가 지나치게 무거워 영어 제목에는 쓰지 않는다. 영어 페이지 안의 한글(제품 이름 등)은 `lang="ko"`로 감싸 Gasoek One으로 돌아간다. 언어별 값은 CSS 변수 `--display`, `--display-weight`, `--display-stretch`, `--display-tracking`이 `[lang]`에 따라 바꾼다.

**Body Font:** Noto Sans KR Variable. 한국어 본문·내비게이션·버튼·설명 제목을 맡는다. 가변 굵기로 위계를 만들고 일반 본문은 (16px), 행간은 (1.8)이다. 영어 본문은 같은 글꼴에 행간 (1.65)를 쓴다.

**Latin Font:** Archivo Variable. 영문 포스터 문구는 굵기 (900), 폭 (85%)로 밀도 있게 배치한다. 작은 발행 정보, 카드 번호, 언어 전환에도 사용한다. 본문의 영문 회사 이름은 영문 로고와 같은 “SunWorks”로 쓴다. 도메인(sunworks.kr)과 대문자 장식 문구는 예외다. 폭 축이 있는 `wdth.css`를 불러와야 `font-stretch`가 실제로 적용된다.

세 글꼴은 [Base](../src/layouts/Base.astro)에서 Fontsource로 자체 제공한다. [OFL 라이선스](../public/assets/font-licenses/)를 함께 보관한다. 루트의 안티앨리어싱, 제목의 `text-wrap: balance`, 본문의 `text-wrap: pretty`를 유지한다. 바뀌는 카드 번호에는 `tabular-nums`를 적용한다. 글꼴 파일은 크기와 관계없이 별도 파일로 내보낸다(`astro.config.mjs`의 `assetsInlineLimit: 0`). 작은 한글 조각이 CSS에 base64로 들어가면 첫 화면을 막는 CSS가 커진다.

YAML 토큰은 design.md 규격상 고정값만 받는다. 그래서 `headline.fontSize` (45px)는 실제 CSS `clamp(32px, 3.05vw, 45px)`의 최댓값이고, `rounded.circle` (9999px)는 실제 CSS `50%`와 같은 정원을 뜻한다.

**자간과 줄바꿈.** 큰 제목의 자간은 Gasoek One (+0.03em), 영어 제목 (-0.015em), 설명 제목 (-0.02em), 그 밖의 굵은 한 줄 문구는 (-0.015em)이다. -0.03em보다 좁히지 않고, Gasoek One은 0 아래로 좁히지 않는다. 카드 저장 이미지도 같은 자간(96px 기준 3px)을 쓴다.

**행간.** 행간은 역할마다 한 값만 쓴다. 값은 `:root`/`[lang]`의 CSS 변수가 언어에 따라 바꾼다. 제목 글꼴(Gasoek One·영어 Archivo)은 포스터처럼 촘촘하게, 본문은 넉넉하게 둬서 두 역할의 차이를 키운다.

| 변수                | 한국어 | 영어 | 적용                                                   |
| ------------------- | ------ | ---- | ------------------------------------------------------ |
| `--display-leading` | 1.06   | 0.95 | 첫 포스터, 제품·인쇄소 제목, 제품 이름, 카드 질문, 404 |
| `--heading-leading` | 1.3    | 1.2  | 소개·제작 기준·마무리 제목, 제품 한 줄 소개            |
| `--lead-leading`    | 1.55   | 1.4  | 첫 화면 문장, 소개 첫 문장, 제작 기준 항목 제목        |
| `--body-leading`    | 1.8    | 1.65 | 16px 본문과 제목 옆 설명, 인쇄소 초대 문구, 제품 메모  |

하한은 글자 잉크 높이로 정했다(2026-10-08 브라우저 측정값). Gasoek One은 위아래 잉크 합이 0.90em이라 1.06에서 줄 사이에 0.16em이 남는다. Archivo는 y의 아래 끝과 f의 위 끝 합이 0.93em이라 0.95 아래로 내리면 두 줄이 닿을 수 있다. 영문 장식 문구(`lang="en"`)는 한국어 홈에서도 영어 값을 쓴다. 그림 설명(1.7), 장식 한자(1.1), 회사 정보(1.6)는 이 네 역할 밖이라 따로 둔다. 한국어는 단어 가운데에서 줄이 바뀌지 않도록 루트에 `word-break: keep-all`과 `overflow-wrap: break-word`를 둔다. 문구의 강제 줄바꿈 앞에는 공백을 넣어, 줄바꿈을 숨기는 좁은 화면에서도 띄어쓰기가 남게 한다.

### 위계와 큰 활자의 예외

| 역할                    | 실제 크기·행간                                                         | 적용                                      |
| ----------------------- | ---------------------------------------------------------------------- | ----------------------------------------- |
| 첫 포스터               | `clamp(78px, 8.7vw, 132px)` / 1.06                                     | “쓸모 있는”. “딴생각.”은 1.32배           |
| 영어 첫 포스터          | `clamp(64px, 7.2vw, 112px)` / 0.95                                     | “Useful”. “daydreams.”는 1.08배           |
| 한글 설명 제목          | 앞의 `headline` 토큰                                                   | 소개·제작 기준·마무리 제목                |
| 제품/인쇄소 포스터 제목 | `clamp(42px, 4.65vw, 68px)` / 1.06, `clamp(45px, 4.65vw, 69px)` / 1.06 | 디스플레이 글꼴. 영어는 행간 0.95         |
| 영문 포스터             | `clamp(52px, 6vw, 87px)` / 0.95                                        | 제작 기준 옆 장식 문구                    |
| 인쇄 카드 질문          | `clamp(32px, 3.45vw, 49px)` / 1.06                                     | 카드 내부의 세 줄 질문. 영어는 행간 0.95  |
| 보조 정보               | 주로 12–14px                                                           | 제품 상태·메모·내비게이션. 본문 대체 금지 |

첫 포스터는 일반 UI의 6rem 범위를 넘는 의도적인 작품 영역이다. (1600px) 이상에서는 기본 글자가 (136px), (1100px) 이하에서는 (8.5vw), (760px) 이하에서는 `clamp(61px, 15.8vw, 105px)`가 된다. 모바일 강조 단어는 (1.24배), (360px) 이하 기본 글자는 (15.8vw)다. 영어 첫 포스터는 “daydreams.”가 한 줄에 들어가도록 (1600px) 이상 (116px), (1100px) 이하 (7vw), (760px) 이하 `clamp(46px, 13vw, 84px)`와 강조 1배, (360px) 이하 (13vw)를 쓴다. 좁은 화면에서 활자만 줄이지 않고 그림과 설명의 배치도 함께 바꾼다.

**The Poster Exception Rule.** 기념비적인 크기는 포스터 제목과 브랜드 표현에 한정한다. 본문·버튼·내비게이션까지 확대하거나 디스플레이 글꼴로 장문을 조판하지 않는다.

## Layout

기본 컨테이너는 `min(1320px, calc(100% - 112px))`이며 좌우 여백은 각각 (56px)다. 여백과 두 열의 비대칭으로 포스터·본문·제품이 숨 쉴 공간을 만든다. 전역 spacing 척도는 없으므로 기존 섹션의 리듬을 참고하고 새 토큰을 추정하지 않는다.

| 화면 폭     | 현재 배치와 여백                                                  |
| ----------- | ----------------------------------------------------------------- |
| 1100px 초과 | 최대 (1320px), 좌우 (56px). 큰 섹션의 두 열 간격은 주로 (80–90px) |
| 1100px 이하 | 좌우 (36px). 주요 간격은 (38–48px), 긴 데스크톱 강제 줄바꿈 해제  |
| 760px 이하  | 좌우 (20px). 주요 영역 한 열. 첫 화면은 제목·그림·설명 순서       |
| 360px 이하  | 좌우 (16px). 로고·메뉴 간격·카드 글자와 내부 여백 추가 축소       |
| 1600px 이상 | 컨테이너는 유지하고 첫 포스터의 활자·위쪽 간격만 조정             |

본문의 최소 지원 폭은 (320px)다. 소개 본문 폭은 데스크톱 최대 (510px), 한 열에서 최대 (580px)다. 모바일 인쇄 카드 영역은 최대 (540px)다. 소개·제작 기준은 데스크톱 약 (100–138px), 모바일 약 (72–78px)의 세로 여백을 사용한다. 제품·인쇄소·마무리는 내용에 맞는 별도 간격을 가진다.

헤더 높이는 기본 (94px), 모바일 (76px)다. 메뉴는 “우리의 생각”, “만든 것”, “딴생각 인쇄소”, 언어 전환(EN/KO) 순서다. 모바일에서는 인쇄소 바로 가기만 숨기고 언어 전환은 (320px)에서도 남긴다. 인쇄소 자체는 페이지에서 계속 접근할 수 있다. 고정 헤더나 접이식 메뉴는 없다. 앵커 섹션은 (28px)의 스크롤 여유를 둔다.

## Elevation & Depth

대부분의 면은 평평하다. 배경색 전환, 가는 인쇄선, 겹친 그림과 원형 해로 공간을 나눈다. 제품 전체를 카드 상자에 넣거나 3D 조명을 추가하지 않는다.

인쇄 카드만 실제 종이 한 장처럼 두 겹의 부드러운 그림자를 갖는다: `0 14px 28px rgba(0, 0, 0, 0.2), 0 2px 6px rgba(0, 0, 0, 0.12)`. 장식용 포스터 문구와 제품 그림의 작은 회전은 정적인 배치이며 반복 애니메이션이 아니다.

**The Paper Depth Rule.** 그림자는 손에 가져갈 인쇄 카드에 둔다. 헤더·일반 버튼·disclosure에 같은 부피감을 복제하지 않는다.

## Shapes

버튼은 작은 둥근 모서리, 종이 카드는 각진 모서리, 해는 동심원으로 구분한다. 제품 앱 아이콘의 (12px) 모서리는 해당 자산의 로컬 처리이며 별도 전역 radius 척도가 아니다. 아이콘 경계에는 `1px solid rgba(0, 0, 0, 0.1)` outline과 (-1px) offset을 둔다.

[Arrow](../src/components/Arrow.astro)는 수평·대각선 두 SVG 경로를 사용한다. 선은 `currentColor`, 굵기는 (1.6), 기본 크기는 (24px)다. 메뉴는 (18px), 저장은 (20px), 푸터는 (16px)로 조정한다. 저장 아이콘도 같은 굵기를 쓴다. Disclosure의 더하기·빼기는 (18 × 2px) CSS 선이며 문자 기호로 대체하지 않는다.

## Components

### 로고와 식별 자산

[BrandLogo](../src/components/BrandLogo.astro)는 한국어 홈에서 제공받은 `sunworks-korean-logo.png`, 영어 홈에서 `sunworks-english-logo.png`(“SunWorks!”)를 쓴다. 검정 컨테이너를 가로세로비 (2.8)로 만들고 `overflow: hidden`, 이미지 `object-fit: cover`로 주변 검정 여백만 화면에서 잘라낸다. 영문 로고 파일은 소유자가 준 원본을 글자 경계까지 자른 뒤 같은 (2.8) 틀에 검정 여백을 더한 것이다(910 × 325px). 두 로고 모두 글자 모양·기울기·내부 그라데이션은 수정하지 않는다.

헤더 로고 폭은 기본 (171px), 모바일 (122px), 가장 작은 화면 (100px)다. 가장 작은 화면 값은 언어 전환이 들어갈 자리를 위해 (110px)에서 줄였다. 푸터는 `min(850px, 85%)`, 모바일에서는 컨테이너 전체 폭이다. 별도 여백 수치나 최소 인쇄 크기는 아직 정하지 않았다.

영문 로고는 2026-10-07 소유자가 제공했다. 대체 텍스트는 “SunWorks”다. 로고를 바꿀 때는 공통 로고 컴포넌트·대체 텍스트·노출 크기와 공유 이미지를 함께 갱신한다. 임시 활자나 생성 이미지로 새 공식 로고를 만들지 않는다.

[파비콘](../public/favicon.svg)은 로고와 같은 검정 바탕 위로 세 겹의 해가 떠오르는 소형 보조 기호다. 한글 주로고의 대체물이 아니며 로고를 줄이거나 다시 그리지 않는다. 세 겹 원은 인쇄 카드의 해 도장에서, 색은 해질녘 그라데이션의 세 값(`#ed5427`, `#f99535`, `#ffdc56`)에서, 오른쪽이 10° 올라가는 지평선은 앞으로 기운 로고에서 가져왔다. 16px 탭에서도 세 겹 반원이 읽히는지 확인했다. 파일은 SVG, `favicon.ico`(16·32·48px), iOS 홈 화면용 `apple-touch-icon.png`(180px, iOS가 모서리를 깎으므로 꽉 찬 정사각형)다. 공유 이미지는 언어별로 하나씩 있다. [한국어](../public/social-card.png)는 한글 로고, [영어](../public/social-card-en.png)는 영문 로고에 포스터 제목·일러스트를 조합한 (1200 × 630px) 이미지이며, 제목 활자는 각 언어의 디스플레이 글꼴을 쓴다. [Base](../src/layouts/Base.astro)의 OG 이미지·설명·locale과 `summary_large_image`, 테마색도 현재 브랜드와 맞춘다.

- **사업자 정보 확인:** 등록번호 옆 링크는 국세청 홈택스의 “사업자상태 조회(사업자등록번호)” 화면을 새 창으로 연다. 로그인 없이 과세 유형과 계속·휴업·폐업 상태를 확인할 수 있다. 주소로 번호를 미리 넣을 수 없어서 번호는 `user-select: all`로 한 번에 선택되게 한다. 통신판매업 신고 전이므로 공정위 조회 링크는 쓰지 않는다.
- **배치:** 데스크톱 4열, (1100px) 이하 2열, (760px) 이하에서는 등록번호·주소·이메일이 한 줄 전체를 쓴다. 이름표는 (12px), 종이색 66% 불투명도, 값은 (14px)다. 링크의 누르기 영역은 (44px)이며 hover는 다른 푸터 링크처럼 노랑이다.
- **두 언어:** 영어 홈은 영문 주소·“Sun Nam”·“June 12, 2026”을 쓰고, 다른 언어로 쓴 상호는 `lang` 속성으로 감싼다.

### 버튼·링크·내비게이션

채운 버튼은 최소 높이 (56px), 아이콘 간격 (26px)이다. 인쇄소의 모바일 “다음 딴생각”은 (52px), 가로 패딩 (18px), 아이콘 간격 (16px)로 줄인다. (360px) 이하에서는 영어 “Next daydream”과 저장 버튼이 한 줄에 들어가도록 가로 패딩 (14px), 아이콘 간격 (12px)로 더 줄인다. 버튼 글자는 줄바꿈하지 않는다(`white-space: nowrap`). 저장·일반 텍스트 링크는 최소 (48px), 푸터 링크는 (44px)다.

**언어 전환:** 헤더 마지막 링크. 화면 글자는 EN/KO 두 글자이고, 스크린리더 이름은 화면 글자를 앞에 둔 “EN (English)”/“KO (한국어)”다(WCAG 2.5.3, 음성 입력으로 “EN”을 말해도 선택됨). `hreflang`과 `lang`을 함께 둔다. Archivo (650), 자간 (0.06em), 왼쪽에 (1px) 옅은 종이색 구분선을 둔다. 누르기 영역은 다른 메뉴와 같은 (48px) 높이다. 두 홈은 `<link rel="alternate" hreflang>`으로 서로를 알린다.

| 상태        | 현재 반응                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------- |
| 기본        | 잉크 버튼은 종이 글자, 종이 버튼은 잉크 글자                                                      |
| Hover       | hover 가능한 포인터에서 버튼 배경이 노랑. 메뉴·저장·푸터 링크도 노랑. 텍스트 링크 밑줄은 2px      |
| 눌림        | 채운 버튼과 저장 버튼의 `scale: 0.96`                                                             |
| 키보드 초점 | 3px `currentColor` outline, 5px offset. 채운 버튼은 주변 면에서 보이도록 잉크/종이 outline을 지정 |
| 저장 중     | 저장 버튼만 비활성, 불투명도 0.65, wait cursor, `aria-busy="true"`                                |
| 모션 감소   | transition 0초, 눌림 배율 1, 부드러운 스크롤 해제                                                 |

버튼은 배경색·글자색·배율만 (180ms), `cubic-bezier(0.2, 0, 0, 1)`로 전환한다. `transition: all`을 쓰지 않는다. 키보드로 보이는 “본문으로 바로 가기”는 `#main`으로 이동한다. 외부 제품 링크는 새 창임을 스크린리더에 알린다.

### 제작 기준 disclosure

네이티브 `details/summary` 세 항목이 같은 이름의 그룹을 이루며 첫 항목은 처음부터 열린다. 제목은 (22px / 750), 행 높이는 최소 (86px)이며 모바일은 (20px / 79px)다. 큰 굵은 제목의 hover는 주홍으로 바뀐다. 열림 상태는 세로선이 (180ms) 회전해 더하기에서 빼기로 바뀐다. 내용은 키보드와 JavaScript 없는 환경에서도 열린다.

### 딴생각 인쇄소

[IdeaPress](../src/components/IdeaPress.astro)와 [동작 코드](../src/scripts/idea-press.ts)는 언어별로 작성된 네 개의 질문을 순환한다. 질문과 안내 문구는 [문구 사전](../src/i18n.ts)에서 data 속성으로 넘긴다. “만들겠다는 약속은 아니고요.”라는 설명을 유지한다. 질문을 생성하는 AI 서비스나 출시 예정 제품 목록이 아니다.

종이 비율은 (1.04), 내부 여백은 앞의 컴포넌트 토큰이다. (1100px) 이하 (24px), 모바일 (23px), 가장 좁은 화면 (20px)로 조정한다. 질문은 `aria-live="polite"`, `aria-atomic="true"`이며 카드 번호는 고정 폭 숫자다.

- **다음 딴생각:** 새 질문을 즉시 반영하고, 기존 동작을 취소한 뒤 위 (12px)·회전 (-0.8도)·불투명도 (0.7)에서 제자리로 한 번 인쇄한다. 길이 (420ms), 곡선 `cubic-bezier(0.16, 1, 0.3, 1)`. 자동 재생·상시 루프는 없다.
- **모션 감소:** 인쇄 동작을 건너뛰고 내용은 즉시 바뀐다. 설정이 켜지는 도중에도 진행 중 애니메이션을 취소한다.
- **JavaScript 없음:** 첫 질문과 설명은 보이며 조작 버튼은 숨겨진다. 스크립트 초기화 후에만 버튼이 나타난다.
- **카드 저장:** 누른 시점의 선택을 고정하고 글꼴을 준비한 뒤 (1080 × 1350px) PNG로 내보낸다. 질문 활자는 한국어 Gasoek One (96px, 자간 3px, 줄 간격 1.06배), 영어 Archivo (750, semi-condensed, 줄 간격 0.95배)다. 캔버스는 폭을 키워드로만 받으므로 화면의 (85%)와 가장 가까운 semi-condensed (87.5%)를 쓴다. 파일명은 `sunworks-daydream-N.png`다. 저장 도중 다음 질문을 눌러도 저장 대상은 바뀌지 않는다.
- **상태·실패:** `role="status"`로 “카드에 잉크를 올리는 중…”, “카드를 준비했어요. 다운로드 목록에서 확인해 주세요.”를 안내한다. 실패 시 “카드를 저장하지 못했어요. 잠시 후 다시 눌러 주세요.”를 표시하고 버튼과 busy 상태를 복구한다. 브라우저의 실제 다운로드 완료까지 단정하지 않는다.

**The Finite Print Rule.** 사용자가 누른 한 번의 인쇄만 움직이고 멈춘다. 반복 클릭·모션 감소·저장 실패에서도 읽기와 다음 조작을 보존한다.

### 제품·이미지·오류 페이지

어흥!한자는 실제 소유 제품으로 소개하고 “정식 출시 준비 중 · 웹 베타 공개”를 유지한다. 주 버튼(잉크)은 제품 소개 사이트 [hanja.sunw.kr](https://hanja.sunw.kr/)로, 옆의 텍스트 링크는 웹 베타(앱 자체, [hanja-app.sunw.kr](https://hanja-app.sunw.kr/))로 간다. 둘 다 새 창이며 스크린리더에 알린다. 마무리 섹션의 링크도 제품 소개 사이트로 간다. 호랑이에는 설명 alt, 이름 옆 앱 아이콘에는 빈 alt를 둬 중복 읽기를 줄인다. 영어 홈에서는 한글 제품 이름 옆에 읽는 법 “Eoheung! Hanja”를 작은 Archivo로 붙인다. 공식 영문 이름이 아니므로 로고처럼 다루지 않는다. 제품 특징은 밑줄을 가진 설명 목록이며 선택 가능한 필터가 아니다. 소개 문구의 사실(아빠가 중학생 아들에게 한자를 가르치려고 만들고 아들 의견으로 고친 이야기, 급수 시험 8급~1급 3,500자, 12시간 뒤 다시 맞혀야 익힘)은 소개 사이트 hanja.sunw.kr 공개 내용을 따른다(2026-10-08 확인). 아빠와 아들 이야기는 소유자가 2026-10-08에 허락했다. 어흥!한자 소개에만 쓰고, 썬웍스의 창업 이야기나 회사 전체 소개로 넓히지 않는다. 앱은 한국어 화면만 지원한다(앱 `flutter_app/lib/main.dart`의 `supportedLocales`가 `ko` 하나).

## Do's and Don'ts

### Do:

- **Do** 제공된 한글 로고를 보존하고 현재 팔레트·자체 제공 글꼴을 재사용한다.
- **Do** 관찰·행동·실제 제품을 한국어로 설명하고 교육을 첫 제품의 영역으로 둔다.
- **Do** 큰 포스터와 읽기용 본문의 위계를 분리하고 작은 화면에서도 두 핵심 메뉴를 남긴다.
- **Do** 키보드 초점·네이티브 disclosure·정적 첫 카드·모션 감소·저장 실패 복구를 유지한다.
- **Do** 래스터 자산의 출처와 생성 여부를 기록하고 공유 이미지도 현재 브랜드와 함께 갱신한다.
- **Do** 한국어 홈을 기준으로 두고, 영어 문구는 같은 태도로 따로 쓴다. 두 언어 문구는 문구 사전 한 곳에서 고친다.
- **Do** 한국어에는 `keep-all` 줄바꿈을 유지하고, 제목 자간을 -0.03em보다 좁히지 않는다.

### Don't:

- **Don't** 제공된 한글·영문 로고를 다시 그리거나 임시 활자로 새 로고를 만든다. 제품 읽는 법(“Eoheung! Hanja”)을 공식 영문 이름처럼 쓰지 않는다.
- **Don't** Gasoek One 제목의 자간을 0 아래로 좁혀 음절끼리 붙게 한다.
- **Don't** 주민등록번호, 증명서 원본, 주소의 호수, 확인하지 않은 전화번호를 회사 정보에 싣는다.
- **Don't** 코발트·3D 조형물을 현 브랜드의 기본 표현으로 되돌리거나 그림자를 일반 UI에 확장한다.
- **Don't** 고객·수치·팀 이력·직원 사진·추천사를 꾸미거나 질문 카드를 실시간 AI 결과로 소개한다.
- **Don't** 주홍을 작은 본문에 쓰거나 대비 확인 없이 그라데이션의 색·글자 불투명도를 바꾼다.
- **Don't** 장식용 소제목을 늘리거나 SVG 아이콘을 문자 기호로 바꾼다.
- **Don't** 현재 없는 입력 폼·필터·다크 모드·전역 모션 설정을 이 가이드에서 추정한다.
