# SunWorks 홈페이지 브랜드 필름

2026-10-08 수정본. 소유자가 이전 영상의 방사형 무늬를 제외하고 더 세련된 모션을 요청했다. 마지막 로고 조건은 해제됐으며 길이를 늘려도 된다는 후속 요청에 따라 **16초·30fps·무음 루프**로 제작한다.

## 구성과 의도

큰 제목을 포함한 헤더 아래 전체 폭. 사이트의 “쓸모 있는 딴생각.”을 하나의 노란 해와 종이의 움직임으로 잇는다. 한국어는 해·빛·떠오름, 영어는 SUN과 WORK의 관계를 강조한다. 회사 이름의 유래나 제품 기능을 새로 주장하지 않는다. 색과 글꼴은 DESIGN.md를 따르며 새 패키지는 추가하지 않는다.

방사형 햇살·살·줄무늬·확산 무늬는 전혀 사용하지 않는다. 기존 `making-sun.webp` 삽화와 로고도 영상에 삽입하지 않는다. 원형 해는 장식이며 새 회사 로고가 아니다. 실제 소유자 로고는 홈페이지 헤더에서 유지된다. 렌더링의 입체감은 종이 접힘·그림자에 한정한다.

## 제작 규격과 재현

- 가로: 1920×960, 2:1. 세로: 1080×1440, 3:4. 세로판은 별도 구도이며 가로판의 중앙 크롭이 아니다.
- 한국어·영어 × 가로·세로, 네 마스터. 각 480프레임. H.264 MP4와 VP9 WebM, 오디오 스트림 없음.
- 첫 이미지: 제목을 포함한 WebP 포스터. 실측 용량은 `public/assets/motion/manifest.json`이 기준이다.

1. 기존 Node·Python(Pillow)·FFmpeg를 사용한다. `scripts/motion/copy.json`은 `src/i18n.ts`의 제작용 스냅샷이다. 사이트 카피가 바뀌면 필요한 필드를 동기화한다.
2. 프로젝트 루트를 로컬 정적 서버로 열고 `scripts/motion/studio.html?lang=ko&format=desktop`에 접근한다. `lang=en`, `format=mobile`로 다른 조합을 연다. 글꼴은 기존 `node_modules`의 자체 제공 글꼴이다.
3. 브라우저는 Phi의 `sunworks-hero-showreel-production` Agent Space를 사용한다. `enterContext({ kind: 'agent', name: 'sunworks-hero-showreel-production' })` 이후 kind와 spaceId를 확인한다.
4. `window.film.ready` 이후 `film.frame(n)`을 n=0..479로 호출한다. PNG base64를 `/tmp/sunworks-film-frames-v2/{lang}-{format}/{0000..0479}.png`에 저장한다. `film.poster()`는 같은 폴더의 `poster.png`다. 프레임은 벽시계·난수에 의존하지 않는다.
5. `node scripts/motion/encode.mjs /tmp/sunworks-film-frames-v2` 실행. `--reuse-video`는 영상 프레임이 변경되지 않은 경우에만 사용한다.
6. 인코더는 16초·30fps·480프레임·영상 스트림 하나와 파일별 2.5MiB 이하/포스터 180KiB 이하를 검사한다. MP4는 faststart를 사용한다.

## 홈페이지 동작

- 첫 화면에는 반응형 포스터를 먼저 표시한다. 영상의 초기 src는 없고 preload=none이다.
- 페이지 로딩 후 idle 시점이며 영상이 보일 때만 현재 언어·뷰포트·코덱에 맞는 URL 하나를 선택한다.
- 실측 용량이 작은 H.264 MP4 우선. 실패하면 지원되는 환경에서 VP9 WebM을 한 번 시도한다. 두 형식을 함께 preload하지 않는다.
- 모션 감소, Save-Data, 2G에서는 자동 영상 요청이 없다. 사용자가 재생을 누르면 재생한다.
- 내려받은 영상은 반복 재생한다. 화면 밖·숨긴 탭에서는 정지하며 사용자 일시 정지는 자동 해제하지 않는다.
- JavaScript나 영상이 실패해도 제목을 포함한 포스터·소개·제품 링크는 남는다.

## 검증

2026-10-08 수정본 검증. Phi Agent Space `sunworks-hero-showreel-production`에서 로컬 Astro 서버를 사용했다. 예전 코드를 유지하던 개발 서버는 소유한 실행 핸들로 정상 종료·재시작하고 아래 검사를 다시 수행했다.

- `/`와 `/en/`, 각각 1440px·390px: 실제 화면 확인. 제목·포스터·언어별 가로/세로 영상 정상, 가로 넘침 없음. 각 환경에서 MP4 URL 한 개만 요청한다.
- 16초 재생 후 처음으로 돌아오는 실제 반복 재생 확인. 무음·재생/일시 정지 버튼 확인.
- 네 가지 모션 감소 환경에서 자동 영상 요청 0건, 제목을 포함한 포스터 유지.
- 화면 밖 정지·복귀 재생, 사용자 일시 정지 유지, Enter 키 정지 확인. MP4 차단 시 WebM 복구, 양쪽 실패 시 포스터·안내 복구. Save-Data에서는 자동 요청 0건, JavaScript 비활성화에서도 제목·포스터 유지.
- FFprobe: 여덟 영상 모두 16초·480프레임·30fps·영상 스트림 하나, 오디오 없음. 네 MP4는 `moov`가 `mdat` 앞에 있는 faststart 구조.
- 네 마스터 모두 첫 프레임·마지막 프레임·포스터 원본의 SHA-256 일치. 마스터와 전환부 장면 모음을 직접 확인해 해의 중복, 빈 색면 전환, 종이 가장자리의 끊김을 수정했다.
- `npm run verify` 통과: 형식·타입·프로덕션 빌드, 오류/경고/힌트 0. 정상 재생 경로의 브라우저 콘솔·실패 요청 0.
